# Northline

A polished financial dashboard built with React, TypeScript, Vite, and Recharts.

## Features

- Net worth overview with trend chart
- Monthly income, expenses, and savings rate KPIs
- Spending breakdown by category
- Linked accounts and portfolio allocation
- Recent transactions and market watchlist
- Responsive layout for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
